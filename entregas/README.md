# Archivos listos para instalar

| Archivo | Plataforma | Qué hacer |
|---|---|---|
| **PortalDroid.exe** | Windows 10/11 | Doble clic. Portable, no instala nada. Vive en la bandeja del sistema. |
| **PortalDroid.apk** | Android 12+ | Copialo al celular e instalalo. Android va a pedir permiso para instalar de fuentes desconocidas. |

Los dos tienen que estar en la misma red WiFi. La guía completa está en el [README principal](../README.md).

> Estos binarios son builds de depuración (`debug`). Para compilar desde el código fuente, ver la sección "Compilar desde el código" del README principal.
